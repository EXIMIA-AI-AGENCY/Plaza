# Contributing to PLAZA

PLAZA is an open protocol. The most useful contribution is a node: a business, a vertical, a country. See `docs/build-a-node.md` (day 3) and `examples/node-template`.

- Spec changes go through a pull request against `docs/protocol/` and `packages/spec/schemas/`, with examples and tests.
- Code: TypeScript strict, `pnpm lint && pnpm typecheck && pnpm test` green.
- Commits: short, imperative, in English.
- Security issues: email security@eximiahq.com instead of opening a public issue.
- Licensing: by contributing you agree your contribution is licensed under Apache 2.0.
