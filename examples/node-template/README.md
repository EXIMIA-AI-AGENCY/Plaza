# node-template

A minimal PLAZA node in one file. Arrives on day 3 (EXI-727). It will:

1. Generate an identity (`@plaza/sdk`)
2. Serve a signed manifest at `/.well-known/plaza.json`
3. Answer `inquiry` with a `quote` from simple rules
4. Register itself in an index

If you are building in the Meta hackathon and your project sells anything, this is how you plug it into Muse through PLAZA in an afternoon.
