# @plaza/spec

JSON Schemas (draft 2020-12), examples and validation helpers for the PLAZA protocol v0.1. The human-readable spec is in [`docs/protocol/v0.1.md`](../../docs/protocol/v0.1.md).

The signatures in `examples/` are placeholders of the right shape. Real signatures come from `@plaza/sdk`.

```ts
import { checkManifest, checkMessage, checkReceipt } from "@plaza/spec";
```
